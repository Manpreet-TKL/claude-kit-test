### T1: profiler/bin/oe_q.sh

- Classification: non-product tooling issue; excluded from the verified target.
- Symptom: The read-only guard read its input line by line after tr ';' '\n', so every continuation line of a multi-line query was judged as its own statement. SELECT a,\n b FROM t was refused because line 2 starts with b.
- Impact: Agents silently worked around it by cramming SQL onto one line; a long one-liner is harder to review, and the guard looked stricter than it was.
- Original status: fixed - strip line comments per line, flatten newlines, then split on ;
- Source location: `BUGS.md:188`.
